# FIDO2 Guard v2.7

Gestionnaire Linux FIDO2, authentification PAM KDE et verrouillage facultatif au retrait.

## Installation

```bash
git clone https://github.com/Maxime3d77/fido2-guard.git
cd fido2-guard
sudo bash fido2-guard.sh
```

## Mise à jour

```bash
git pull --ff-only
sudo bash fido2-guard.sh
```

Attention : projet pilote, conserver le mot de passe et une console de secours ; tester PAM/KDE avant de déployer.
